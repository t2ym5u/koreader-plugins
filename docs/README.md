# KOReader Plugins

> ⚠️ **Stability notice** — These plugins have only been tested on **Kobo** devices running KOReader. Other devices (Kindle, PocketBook, Android) may work but are untested. Use at your own risk.

A collection of game and utility plugins for [KOReader](https://koreader.rocks/), the open-source e-reader application.

## 🌍 Language support

All plugins auto-detect the KOReader display language:

- **French** (`fr`) — buttons, menus, status messages, and rules dialogs displayed in French.
- **English** (default) — used for any other language setting.

The translation table lives in `game-common/i18n.lua`. To add German, Spanish, or any
other language, add a `de`, `es`, … key to entries in that file — no plugin code needs to change.

## 📦 Installation

### Via Plugin Manager (recommended)

1. Download [`pluginmanager.zip`](https://github.com/t2ym5u/koreader-plugins/raw/master/dist/pluginmanager.zip)
2. Extract into your KOReader `plugins/` directory
3. Restart KOReader
4. Open **Plugin Manager** from the menu to browse and install games

### Manual installation

1. Download the `.zip` of the plugin you want from [`dist/`](dist/)
2. Extract into your KOReader `plugins/` directory
3. Restart KOReader

## 🛠 Development

Each game lives in its own repository (git submodule). To work on a plugin locally:

```bash
git clone --recurse-submodules https://github.com/t2ym5u/koreader-plugins
cd koreader-plugins
./scripts/build_release.sh <plugin-id>   # build a single plugin
./scripts/build_release.sh               # build all plugins
```

Output zips are written to `dist/`.
