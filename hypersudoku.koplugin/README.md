# Hyper Sudoku — KOReader Plugin

> Standard 9×9 Sudoku with four extra shaded 3×3 regions that must also contain each digit 1–9 exactly once.

## Rules

- Standard 9×9 Sudoku: each row, column, and 3×3 box contains digits 1–9 exactly once.
- Four extra 3×3 hyper-regions (rows 2–4 and 6–8, columns 2–4 and 6–8) must also each contain digits 1–9 without repetition.

## How to Play

1. Tap a cell to select it.
2. Tap a digit button to fill it in.
3. Use **Note** mode to pencil in candidates.
4. **Check** highlights errors in red.
5. **New game** generates a fresh puzzle.

## Hyper Regions

The four extra regions are positioned symmetrically inside the 9×9 grid:

| Region | Rows | Columns |
|--------|------|---------|
| Top-left | 2–4 | 2–4 |
| Top-right | 2–4 | 6–8 |
| Bottom-left | 6–8 | 2–4 |
| Bottom-right | 6–8 | 6–8 |

Each hyper-region is shaded on screen. Duplicate digits within a hyper-region are highlighted in red.
