# Sudoku X — KOReader Plugin

> Standard 9×9 Sudoku with the extra constraint that both main diagonals must also contain each digit 1–9 exactly once.

## Rules

- Standard 9×9 Sudoku: each row, column, and 3×3 box contains digits 1–9 exactly once.
- The main diagonal (top-left to bottom-right) must also contain digits 1–9 without repetition.
- The anti-diagonal (top-right to bottom-left) must also contain digits 1–9 without repetition.

## How to Play

1. Tap a cell to select it.
2. Tap a digit button to fill it in.
3. Use **Note** mode to pencil in candidates.
4. **Check** highlights errors in red.
5. **New game** generates a fresh puzzle.

## Diagonal Constraint

The two diagonals are highlighted with a light background. Any digit placed on either diagonal must be unique along that diagonal in addition to satisfying the standard row, column, and box rules. Conflicts on the diagonals are highlighted in red alongside standard Sudoku conflicts.
